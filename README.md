# 📄 AI Resume Review Agent

A beginner-friendly single-agent resume review application built with:

- Streamlit
- CrewAI
- Groq
- OpenAI GPT-OSS 120B
- PyPDF

## Features

- Paste resume text
- Upload PDF resume
- Paste target job description
- Compare resume against job requirements
- Identify demonstrated and partially demonstrated requirements
- Identify requirements not demonstrated in the resume
- Generate actionable resume improvement recommendations
- Suggest ATS keywords from the job description
- Avoid fabricating qualifications
- Gracefully handle PDF and API errors
